## Scenarios

| Case | Expected boundary |
| --- | --- |
| Owned generated Veo source and observed native Extend surface | One native dispatch; independently correlated extension handle |
| Uploaded or archived source cannot expose Extend | Scoped unsupported source; no restore or fake result |
| Cross-project/media source | Reject before generation |
| Prompt/model/seed/count validation | Reject invalid controls before browser dispatch |
| Abort-only capture | No billable request reaches Google |
| Null/ambiguous acknowledgement | Unknown submission outcome; no retry or first-new-ID adoption |
| Native output differs from source | Source registration preserved; new extension output registered |
| CLI/SDK/REST/MCP mirror | Same standalone output contract; sync/async supplied by existing durable adapter |
| Cancel/timeout after dispatch | Preserve known handles; no submission replay |
