# Character and voice detail scenarios

| Dimension | Must-cover scenario |
| --- | --- |
| D1 auth | Explicit selected profile/project; expiry fails read without alternate-account scan. |
| D2 WAF | No token/solver/generation fallback on lookup error. |
| D3 source | Current exclusive unions; thumbnail relationship proved independently. |
| D4 resume | Never replay fixture creation from ambiguous acknowledgement; preserve handles. |
| D5 concurrency | One page for snapshot/detail; overall checkout+RPC deadline; release once. |
| D6 data | Bearer URLs excluded from catalog/history/queue; no synthesized ownership. |
| D7 platform | Portable selectors/UUID paths and no browser changes to Vivaldi user login. |
| D8 mirrors | SDK/CLI/direct MCP/REST expose same detail controls; queued generation unchanged. |
| D9 validation | Duplicate entity/name/workflow/primary media joins refuse before detail RPC. |
| D10 content | Image previews, avatar thumbnail and audio playback stay distinct. |
| D11 privacy | Trusted measured hosts/ports/credentials/fragments; no URL logging/errors. |
| D12 absence | Missing optional resolution is explicit; incomplete snapshot never proves deletion. |
| D13 evidence | Free character fixture requires source-proven mutation and cleanup; audio live proof not invented. |

Critical tests: wrong project/type/triple; ambiguous workflow→primary mapping;
duplicate reference order; audio/image/video mixed union; untrusted audio URL;
thumbnail absent projection with/without supported independent ownership proof;
empty snapshot/orphan labels; cancellation/checkout cleanup; private worker error
envelope; URL controls direct mirrors/no-store. High: system preset details,
optional voice URL omission, repeated names, deleted entity lookup, bounded RPCs.

BDD: Given a source-proven free owned character fixture and preserved primary
image identities, when detail reads resolve ordered previews and avatar thumbnail,
then URLs match exact owned typed media and no generation is sent; remove only
the acknowledged fixture. No saved voice is created merely for this read test.
