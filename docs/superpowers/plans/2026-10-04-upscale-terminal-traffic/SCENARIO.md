# Scenarios

- Exact singleton SPrCad traffic ErrorInfo or PublicAitkError enum 50: terminal typed quota, no image bytes.
- Explicit provider retry10: one client, one minted token, submitted then rejected; no retry/output.
- Same-RPC positive acknowledgment or null status sibling: unknown and no replay.
- Default browser 2K and 4K: same typed terminal result without provider telemetry.
- Existing WAF retry, supplied-token one-use, 4K entitlement preflight and accepted byte failures retain behavior.
